# Nestodo for Android

Manage your todos from an Android 17 phone.

- Enter the address of your Nestodo server on first launch. Change it later in Settings.
- Sign in with the same Cloudflare Access account as the web app. The login is kept on the phone and renewed without the browser until it fully expires.
- The todos you saw last time open at once. You can read them while the app checks the server and edit once it answers. Signing out removes them from the phone.
- Share a link or text from another app to add it as a todo. A link at the start or end of the text goes to its first comment, and you can edit the title before adding. Pick the todo to add it under from your outline, or search for it. The todo you added under last time is listed first.
- Light and dark follow the system setting.
