# Nestodo for Android

Manage your todos from an Android 17 phone.

- Enter the address of your Nestodo server on first launch. Change it later from the account menu.
- Sign in with the same Cloudflare Access account as the web app. The login is kept on the phone and renewed without the browser until it fully expires.
- Share a link or text from another app to add it as a todo. A link at the start or end of the text goes to the note, and you can edit the title before adding. The todo you added under last time is listed first.
- Light and dark follow the system setting.
